# Security Policy

## Supported versions

This project is under active development. Security fixes are intended for the latest code on the `main` branch and the latest published release, if releases are available. Older versions are not guaranteed to receive security updates.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Latest release | Yes, if available |
| Older releases | No guarantee |

## Reporting a vulnerability

**Please do not report security vulnerabilities in public issues, discussions, or pull requests.**

Use GitHub's **Private vulnerability reporting** feature on this repository, if enabled. If it is not available, contact the repository owner privately through a channel listed on their GitHub profile and include a way to follow up securely.

Please include:
- A concise description and potential impact.
- Steps to reproduce or a proof of concept that does not expose real user data.
- Affected commit, release, operating system, and relevant configuration.
- Any suggested mitigation, if known.

Please avoid attaching real credentials, personal data, or other secrets. Redact sensitive information before sending diagnostic logs.

## Response goals

These are target times, not guarantees:
- Acknowledge a report within 7 calendar days.
- Provide an initial assessment within 14 calendar days.
- Coordinate a fix and disclosure timeline with the reporter where practical.

Please allow reasonable time for investigation and remediation before public disclosure. We appreciate responsible reports made in good faith.
